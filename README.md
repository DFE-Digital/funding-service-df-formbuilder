📋 Project Overview
The Digital Forms Builder repository provides the core codebase for creating dynamic, web-based data collection forms tailored for schools and service providers. It simplifies complex data gathering (such as funding requests and compliance reporting) by supporting flexible HTML layouts and advanced logic.

Key Features
🧩 Standard HTML Components: Build forms using familiar, accessible web components.

🔀 Conditional Routing: Guide users through custom paths based on their previous answers.

🧮 Built-in Calculations: Perform real-time math operations directly inside the form.

🔄 Dynamic Page Repetition: Allow users to duplicate pages or sections as needed (e.g., adding multiple students/providers).

📎 File Uploads: Securely collect supporting documentation alongside form responses.
